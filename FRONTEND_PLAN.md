# FRONTEND_PLAN — Поэтапный план разработки графики FlyGotchi

План фокусируется исключительно на клиентской части (`frontend/`, PixiJS v8 + TypeScript + React + Tailwind CSS) с автономной системой моков для мозга мухи до момента подключения реального Python-бэкенда.

Работа разбита на **4 независимые проверяемые части** — после каждой части проект собирается и его можно проверить в браузере.

---

## Часть 1. Контракт данных, Мок-мозг и базовое подключение (Ядро)

- [x] **1.1. Контракт данных (`frontend/src/types/brain.ts`)**
  - `FlyBehaviorState`: `'idle' | 'grooming' | 'walk' | 'fly' | 'eat' | 'drink' | 'sleep' | 'startled' | 'electrocuted'`.
  - `Neuromodulators`: `{ octopamine: number; dopamine: number; serotonin: number }` (`0..1`).
  - `BrainClusters`: `{ vision: number; olfactory: number; mushroomBody: number; motor: number; hunger: number }` (`0..1`).
  - `BrainTelemetry`: координаты `(x, y)`, цель `(targetX, targetY)`, направление взгляда `lookAngle`, `state`, `neuromodulators`, `clusters`, `tick`, `arena`.
  - `SensoryInputEvent`: `cursor_hover`, `feed_drop`, `dew_drink`, `feather_tickle`, `flashlight`, `electrode_zap`.

- [x] **1.2. Автономный Мок-мозг (`frontend/src/services/MockBrainEngine.ts`)**
  - Планировщик поведения на TypeScript (20 Hz): переходы между состояниями (`idle`, `walk`, `grooming`, `fly`, `eat`, `drink`, `sleep`), плавное движение к целевым точкам, волны спайков в `BrainClusters`, динамика `Neuromodulators` и реакция на `SensoryInputEvent`.
  - Встроенная поддержка ручного override-режима (для подключения Sandbox-панели на следующем шаге).

- [x] **1.3. Единый адаптер (`frontend/src/services/BrainConnection.ts` + `hooks/useBrainConnection.ts`)**
  - Работает через `MockBrainEngine` при `VITE_USE_MOCK_BRAIN=true` (по умолчанию).
  - Содержит готовую заготовку WebSocket-клиента для `ws://localhost:8000/ws/brain`.

- [x] **1.4. Подключение к UI (`App.tsx`, `FlyArena.tsx`, `TelemetryPanel.tsx`)**
  - Обновление сцены и панели телеметрии под новый контракт `BrainTelemetry` и `SensoryInputEvent`, тестовые кнопки стимуляции.

## Часть 4. Японский чиби-риг мухи, аниме-глаза и «Рентген мозга»

- [x] **4.1. Процедурный риг в стиле Super Deformed (Чиби)**
  - Собрать иерархию вложенных `Container` / `Graphics` с пропорциями японского чиби:
    - **Большая голова** — главный и самый крупный элемент персонажа;
    - **Маленькое пухлое тельце** с мягким градиентом и коротенькими милыми лапками;
    - **Маленькие полупрозрачные крылышки** с радужным переливом и усики-антенны, аккуратно выглядывающие вокруг/позади большой головы.

- [x] **4.2. Огромные аниме-глаза, эмоции и зрительный контакт**
  - Заменить фасеточные глаза на выразительные аниме-глаза на пол-лица: крупные зрачки, многослойные блики («искры»), мягкий румянец на щеках и подвижные веки для естественного моргания.
  - Реализовать постоянный зрительный контакт с игроком: зрачки и лёгкий наклон всей большой головы плавно следят за курсором мыши и активными инструментами (`cursor_hover`).
  - Добавить смену глазных эмоций: прищур от удовольствия (`eat` / `drink` / `grooming`), расширенные зрачки от удивления (`startled`), полуприкрытые сонные веки (`sleep`), спиральки после разряда (`electrocuted`) и сердечки при высоком уровне дофамина.

- [x] **4.3. Полный набор фронтальных анимаций по `FlyBehaviorState`**
  - Привязать плавные процедурные анимации ко всем 9 состояниям: `idle` (дыхание и моргание), `grooming` (потирание лапок у мордочки), `walk` (переваливание по мху), `fly` (подъём над землёй и быстрая вибрация радужных крыльев), `eat` и `drink` (выдвижение маленького хоботка к угощению), `sleep` (покачивание с «Zzz»), `startled` (подпрыгивание), `electrocuted` (встряска и разряды).

- [x] **4.4. Режим «Рентген мозга» в большой голове**
  - Добавить в UI переключатель сканера **«Рентген мозга»**.
  - При активации большая чиби-голова переходит в режим полупрозрачной голограммы, внутри которой в реальном времени пульсируют и светятся 5 узлов `BrainClusters` (`vision`, `olfactory`, `mushroomBody`, `motor`, `hunger`) со связями между ними.
